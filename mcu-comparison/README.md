# 三款 STM32 精确料号对比研究

目标：补全用户提供截图中的三个 STM32 列，不复核或改写截图前两个已完成系列的参数。

工作流：主 agent 制定 research-protocol.md → 三个独立分析 agent 并行分析 → 三个不同的审核 agent 分别核验并修订 → 主 agent 汇总。

## 资料范围

- 用户提供的 Windows 本地目录未从云机器直接访问。三份用户上传 PDF 原件保存在 sources/，SHA-256 校验信息见 sources/manifest.json。
- U073：DS14548 Rev 2，2024-03。
- L431：DS11453 Rev 3，2018-05。
- U599：DS13633 Rev 3，2025-05。上传文件名为 DS_stm32u595ai.pdf，但文档覆盖 STM32U59xxx，包含 STM32U599VI。
- ST 官网请求受到当前代理 403 限制，未声称已在线确认这些数据手册为最新版。联网补证使用可访问的 ST / Zephyr 官方 GitHub 文件，具体版本与路径见各分析文件来源列表。

## 读表注意

所有值针对完整订货号，不是系列最大值。GPIO 为该封装总 GPIO 数，不代表所有复用功能可同时使用。外设数量是 IP 实例数，最终 PCB 需另做引脚复用冲突检查。

CoreMark 为手册报告值，不是本次跑分。运行电流和深睡电流的电压、模式、负载、存储保持条件不同，不应直接横向排名。对安全启动、密钥库及加密加速器分别说明，避免由 Cortex 内核或系列名推断。

未知表示现有资料不足；不支持表示已有功能表/框图等依据。没有在目标开发板上构建或实测 Zephyr，仅核实上游 SoC 文件。未执行硬件验证和量产安全配置验证。

analysis/ 保存逐芯片数据与来源；reviews/ 保存独立审核记录。研究文件独立存储，未改动 ChatGPT-Works 仓库。
